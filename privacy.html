Browser-only assessment data

The default public build stores assessment state in browser session storage. The website operator does not receive your answers merely because you use the assessment. Session storage is ordinarily removed when the browser session ends, subject to browser behavior.

Exports

You may deliberately export response or profile files. Exported files can contain highly sensitive information and remain under your control. Protect them accordingly.

External processing

No operator-configured external AI processor is enabled in this public package. Do not enable an external endpoint without updating this notice, obtaining granular authorization, and completing security and privacy review.

Server logs

Your hosting provider may create ordinary technical access logs such as IP address, date and time, requested path, browser information, and error information. Configure and disclose the actual hosting provider and retention period before publication.

Cookies and analytics

This package includes no advertising trackers and no analytics script. Adding analytics or third-party embeds requires an updated privacy review and notice.

Deletion

Use the assessment’s reset controls to remove current browser-session data. Deleting exported files is your responsibility. Server-log deletion depends on the hosting provider’s implemented policy.
